# 视觉质量合同

## 1. 自适应视觉策略

先识别内容类型，再决定主画面语言：

| 内容类型 | 主要视觉 | 辅助视觉 |
|---|---|---|
| 辩论观点 | 对照实景、角色立场、结果场景 | 观点卡、对比卡 |
| 新闻热点 | 事件实景、官方发布、地点与人物 | 时间背景、数据卡 |
| 知识解释 | 过程图、结构图、具体案例 | 关键词、简化数字 |
| 情绪共鸣 | 人物状态、生活细节、环境气氛 | 短句、留白 |
| 产品商业 | 使用场景、设施、操作过程 | 成本、效率、链路 |
| 人物故事 | 人物、地点、行动、历史画面 | 引语、节点信息 |

不要把同一套视觉模板套在所有题材上。

用户未给视觉参考时直接依据上表选择视觉身份，写出 `DESIGN.md` 并推进制作；不要为了主色、风格名称或参考图反复提问。

## 2. 双层分镜

- 宏观章节通常15～30秒，负责一个完整论证或情绪推进。
- 微观镜头通常3～8秒，由语义变化驱动；不是强制计时器。
- 开头3秒展示核心冲突、人物利益或反常识结果。
- 每15～25秒安排一次视觉重置：实景转数据、远景转细节、观点转案例或图片转视频。
- 反问、反驳、数字、说话人态度变化和结论优先成为换镜点。
- 情绪长镜头和复杂数据卡可适当延长，前提是观看目的明确。
- 同一静态画面无理由不连续停留超过8秒。

禁止使用倒计时、时间轴、进度条或为了“保持变化”而机械闪切。

## 3. 画面与素材比例

`standard` 档位参考：

- 实景照片或视频约60%～80%。
- 数据、观点和结构图约20%～40%。
- 至少使用一段经过动态真实性验证的视频素材；题材确实不存在可用视频时，在报告中说明并以更丰富的图片运动补偿。
- 不连续使用三个同类型信息卡。
- 同一素材不在相邻镜头重复。

素材评分维度：语义匹配、来源可信、分辨率、清晰度、色彩、构图空间、水印、背景文字和裁切安全。语义匹配与来源可信优先于纯分辨率。

## 4. 安全区与布局

默认底部安全区为画面高度的16%；720P约116px。安全区内不放：

- 人物面部或关键动作。
- 主标题、关键数字、Logo和CTA。
- 需要观众读懂的图表标签。

横屏720P建议边距：左右64px、顶部48～56px、底部至少116px。其他尺寸按比例缩放。

所有布局先分区再加动画。文字、图片、数据卡不得依靠“看起来差不多”挤在同一区域。每个场景在中点和转场前后运行布局检查并查看实际截图。

禁止可见网格背景、辅助线、模板名称、时间码和镜头编号。CSS布局技术可以使用，但不能让观众看到网格纹理。

## 5. 中文文字

- 720P主标题通常56～76px；核心数字可更大。
- 单行尽量8～16个汉字；通常不超过3行。
- 同屏只保留一个主观点区域和一个辅助信息区域。
- 屏幕文字补充口播，不复刻整段字幕。
- 小标签通常不低于22px，正文通常不低于28px。
- 使用项目内本地中文字体并声明 `@font-face`；未验证字体加载时不得正式渲染。
- 背景素材自带大段文字时，改用干净素材、重新裁切或充分弱化，不让两套文字争夺注意力。

## 6. 色彩和运动

默认优先彩色实景，确保文字与背景有足够对比。不要用纯黑白作为全片唯一视觉，除非用户指定。

图片运动使用克制的推近、平移和遮罩进入；不要让主体漂出安全区。视频素材不无限循环，结束后切到有意义的下一画面。转场以硬切、轻淡化、方向遮罩和运动匹配为主，避免炫技特效抢夺口播。

每个场景有确定性进入动画。除最终CTA外，不为所有元素安排退出动画；避免场景结束前提前消失。

## 7. 关键帧联系表

至少抽取：

- 0.5秒与开头3秒。
- 每个宏观章节中点。
- 每次转场前0.1秒与后0.1秒。
- 每个大字卡稳定显示时刻。
- 每段视频素材的两个不同时间点。
- 结尾CTA稳定显示时刻与最后0.3秒。

把关键帧排成联系表并逐张查看。发现以下任一问题必须修改后重渲染：

- 文字重叠、越界、过小或被裁切。
- 底部安全区被关键信息占用。
- 视频区保持静止或被静态层覆盖。
- 背景文字干扰。
- 黑帧、闪白、素材突然消失。
- 画面语义与正在播放的内容明显不符。

## 8. 结尾

优先使用音频已有评论和关注文案，其次使用用户提供的账号定位。不要擅自发明姓名、账号、承诺或下一期内容。

CTA保持大字、单一动作、充足停留时间；底部继续保留字幕安全区。最后一帧必须完整，不在音频结束前淡出。
